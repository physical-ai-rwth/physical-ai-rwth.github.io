Long-horizon autonomy demands memory that persists and stays organised. We develop
structured memory for embodied agents so that what a robot learned earlier in a task, or
in a previous episode, remains retrievable and useful rather than dissolving into an
undifferentiated context window.

The question is not only what to store, but what to discard, and how to keep the
representation queryable as it grows.
